# Електронний курс «Основи Git та командної розробки для студентів ІТ»

Інтерактивний вебкурс із трьох змістових модулів, вхідної діагностики, симулятора команд Git, парного практикуму Code Review, гейміфікації, прототипу ШІ-помічника GitMentor та панелі навчальної аналітики.

## Локальний запуск
Відкрийте файл `index.html` у будь-якому сучасному браузері (Chrome, Edge, Firefox).

## Публікація на GitHub Pages
```bash
git remote add origin https://github.com/vshpak-kubg/git-teamwork-course.git
git push -u origin main
```
Після пушу у налаштуваннях репозиторію увімкніть `Settings -> Pages -> Source: Deploy from a branch (main / root)`.
